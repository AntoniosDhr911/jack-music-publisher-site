JACK Music Publisher

JACK Music Publisher ("JACK") is a private, internal automation tool used by a small music-publishing team to publish already completed release assets to YouTube and Meta (Facebook/Instagram) through each platform's official API. It is not a public product or service: there is no public sign-up, no public account creation, and no software or account access offered to the general public.

JACK also has a TikTok Content Posting API integration, but per this project's own current decision that integration is used only for development/testing in TikTok's unaudited Sandbox mode. Production TikTok publishing is done manually through TikTok's own normal creator app/website, not through JACK's API automation.

JACK is operated by Jack Daher.
